# Product

## Register

product

## Users

One person, the owner of this machine: a Thai-speaking hobbyist who translates manga. They paste a series URL, pick chapters, and download the page images so a separate translation program (MangaX) can open the chapter folders. Sessions are long and repetitive: many chapters, many series, sometimes late at night, sometimes in a bright room. They are comfortable with tools but do not want to read code or logs to learn what happened.

## Product Purpose

A desktop downloader that turns a series URL into complete, correctly ordered chapter folders on disk. Each website is a separate module, so more sites get added over time. Success means: the user always knows what was downloaded, what is missing, why something failed, and what to do next, without opening a file explorer or a log file.

The app only downloads. Translation happens in another program.

## Brand Personality

Quiet, precise, trustworthy. A sharp tool in the lane of Linear and Raycast: calm surfaces, dense but legible information, nothing decorative. The interface speaks Thai, in short plain sentences, and never hides a problem.

## Anti-references

- The template dashboard: grids of identical cards, hero numbers with small labels, purple-to-blue gradients, anything that reads as generated.
- Decoration that carries no information.

## Design Principles

1. Report everything, shout nothing. Every outcome is visible, and only real problems get strong color.
2. The list is the product. Chapters, series, and sites are rows of data; density and scanning speed beat ornament.
3. State is always answerable: what is on disk, what is running, what failed and why.
4. Every error names its fix in Thai, with the technical detail one step away.
5. Familiar over clever. Standard navigation and controls, so the tool disappears into the task.

## Accessibility & Inclusion

- Light and dark themes, following the Windows setting. Both must be first-class.
- WCAG AA contrast for text and for status indicators in both themes.
- Status is never carried by color alone: pair color with a label or icon.
- Full keyboard operation with visible focus.
- Respect reduced-motion preferences.
- Thai text must render well: use fonts with good Thai glyphs and enough line height for stacked vowels and tone marks.
